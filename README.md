# testtool

常用小工具集合。

## 目录分类

| 目录 | 工具 | 说明 |
|------|------|------|
| `llm-detect/` | `llm_detect.html` | LLM API 检测：批量粘贴自动识别 API/Key/Model，左栏输入问题、右栏配参数、下方看回答 |
| `cloud-clipboard/` | `sync.html` + `upload_server.py` + `start.bat` | 云剪贴板 + 文件互传：手机粘贴、电脑实时显示，双向发送；`start.bat` Windows 一键启动 |
| `pp/` | `pp.sh` | 一体化脚本：下载 Flutter / 克隆仓库 / 推送 / 起上传服务 / flutter 测试 |
